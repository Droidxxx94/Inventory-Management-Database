# Inventory Management Database

A complete SQL + Python inventory management system designed to demonstrate practical data skills including database architecture, CRUD operations, automation, and version control. This project is part of my data analytics portfolio and showcases my ability to design structured data workflows and build maintainable backend systems.

---

## 📦 Project Overview
This system manages core inventory operations:
- Product registration and unique identifiers
- Supplier tracking and relationships
- Stock level updates and adjustments
- Transaction logging for auditability
- SQL queries for reporting and insights

The project is built to mirror real business inventory processes and highlight my ability to design and implement data‑driven solutions.
